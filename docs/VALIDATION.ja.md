# 検証範囲

検証日: 2026年10月8日。

## 学習と評価

- 元画像と塗りを変えた教師画像の6組で学習しました。rank 32、学習率1e-4、batch 1、240更新、最大262,144画素の小規模試作です。
- 学習はBF16モデル、推論評価はQwen Image 2.1のQ4_K_M GGUFで行いました。
- 学習に使わなかった初期2人に、アニメカフェ・ゲームCGの2系列を追加し、計4系列で評価しました。
- 採用raw比較は12枚です。各系列は1つのseedで比較しています。旧ゲームCGの脚に問題があった3枚は採用数へ含めていません。
- 生成結果の変化と、LoRA全224ペア・448テンソルの形状適合を確認しました。すべてのキーがGPU実行中にどう適用されたかの個別追跡は行っていません。

肌の中間色、血色差、柔らかな陰影と丸みを見て評価しました。元から美麗な塗りがあるカフェ・ゲームCGでは効果は穏やかです。自然言語編集より常に高品質になることや、未学習の画風参照に追従すること、幅広い一般化は確認していません。

## マスク合成

学習lossは全領域MSEです。肌だけを重くしたmask lossではありません。教師画像の肌マスク合成や、推論後の肌マスク合成とは区別します。

マスク合成のAPIは2件を実行しました。保存PNGで黒マスク領域のRGBAと、画像全域の元alphaが一致することを検査しました。黒領域はそれぞれ892,781画素、933,293画素です。これは合成後の保持を検証した結果で、rawモデルの肌選択性を証明するものではありません。

## 配布ワークフロー

raw版は採用したゲームCG v2、masked版はカフェで実行・RGBA検証したワークフローを基にしています。

配布時の変更は次の項目です。

- 元画像名を `source.png`、肌マスク名を `skin-mask.png` へ変更。
- LoRAファイル名を `skin-paint-image21-r32-v1.safetensors` へ変更。公開版にはライセンス・モデル由来のmetadataを加え、学習したtensorの内容は維持しています。
- 保存prefixを `SkinPaintImage21/skin-paint-v1-raw` または `SkinPaintImage21/skin-paint-v1-masked` へ変更。
- GUI JSONに埋め込まれたマシン固有の来歴情報を、配布用の最小情報へ置換。

これ以外のノード種類・配線・モデル選択・プロンプト・seed・生成設定は維持しています。APIとGUIから同じ入力・配線・widget値が復元されることをCPUで検査しました。

GUIブラウザーへの実インポートと、差し替え用入力に変更した配布版のGPU再生成は未実施です。環境のノード実装やmodel selectorが異なる場合は、読み込み後にファイルの再指定が必要です。
